# Деплой на бесплатный PHP-хостинг (Beget)

Вариант для России: адрес хостинга открывается без VPN, заявки приходят в Telegram
автоматически. Один и тот же билд работает и тут, и на Cloudflare Pages — клиент сам
пробует сначала `/api/lead` (serverless), затем `/api/lead.php` (PHP).

## Где взять бесплатный хостинг

**Beget** — бесплатный тариф навсегда: https://beget.com/ru/hosting/free
(1 ГБ диска, 1 сайт, PHP 8, MySQL, FTP, до 25 000 файлов, технический домен из панели).

У Timeweb и REG.RU бесплатный период ограничен 10 и 14 днями — это только для теста,
поэтому для постоянного размещения берём Beget.

## Шаг 1. Создайте архив

Из папки проекта в PowerShell:

```powershell
.\deploy\package-php.ps1 -TelegramToken "<токен>" -TelegramChatId "<chat id>"
```

Готовый файл: `deploy/ilya-portfolio-php.zip` (~8 МБ, 43 файла).
Внутри уже есть `index.html`, `assets/`, `projects/` и `api/lead.php` с настроенным
`api/config.php`, где лежат токен и chat id.

## Шаг 2. Залейте на хостинг

Вариант А — через панель Beget:

1. Войдите в панель → раздел **Файловый менеджер** → откройте `public_html`.
2. Кнопка **Загрузить файл** (или «Архивы» → «Загрузить архив») → выберите
   `deploy/ilya-portfolio-php.zip` с компьютера.
3. Распакуйте архив прямо в `public_html` так, чтобы `index.html` лежал в корне
   папки, а не внутри распакованной директории.

Вариант Б — через FTP (FileZilla):

- Хост и логин панель покажет после регистрации (обычно `ftp.beget.com` и ваш логин).
- Загрузите содержимое `dist` в `public_html`, затем отдельно `api/lead.php`
  и `api/config.php` в `public_html/api/`.

## Шаг 3. Проверьте

1. Откройте сайт по техническому домену из панели.
2. Отправьте тестовую заявку — должна прийти в Telegram.
3. Проверка обработчика из PowerShell:

```powershell
curl.exe -X POST "https://<ваш-домен>/api/lead.php" -H "Content-Type: application/json" -d '{"name":"Тест","contact":"@vebairazrabotka","message":"Проверка PHP-обработчика"}'
```

Ответ `{"ok":true}` и сообщение в Telegram — всё работает.

Если придёт `{"ok":false,"error":"not_configured"}` — не создан `api/config.php`
или в нём пустые значения. Если `empty_message` — проверьте, что JSON уходит
без лишних пробелов (у клиента он уходит корректно).

## Шаг 4. Прячем конфиг от посетителей

`api/config.php` лежит в `public_html` и теоретически отдаётся как текст.
Добавьте в `public_html/api/.htaccess` (Apache):

```
<Files "config.php">
  Require all denied
</Files>
```

## Шаг 5. Свой домен

Когда купите домен: Beget даёт бесплатные 3 месяца хостинга при оплате за год,
плюс можно перенести `.ru`/`.рф` к ним бесплатно. В панели: **Сайты и домены** →
привязать домен → прописать NS-серверы Beget у регистратора.
